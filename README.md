# Лабораторные работы по ассемблеру

В репозитории собраны четыре программы на разных учебных архитектурах. Каждая программа решает отдельную задачу, а YAML-файл рядом содержит конфигурацию запуска и проверки в тестирующей системе.

## Тестирование

Запустить и проверить решения можно в [тестирующей системе](https://wrench.edu.swampbuds.me/submit-form).

Для проверки выберите подходящую архитектуру, загрузите исходный `.asm`-файл и используйте соответствующий сценарий `.yaml` как описание теста. В конфигурациях заданы размер памяти, значения для memory-mapped I/O, лимит выполнения, отчёты и ожидаемые результаты.

## Решения

| Файл | Архитектура | Задача |
| --- | --- | --- |
| [`acc.asm`](acc.asm) | acc32 | Вычисление числа Фибоначчи с обработкой отрицательного ввода и переполнения |
| [`f32.asm`](f32.asm) | f32 | Перевод строки в верхний регистр с завершением по `\n` |
| [`m68k.asm`](m68k.asm) | m68k | Сопоставление строки с шаблоном: `*` соответствует последовательности символов, `?` — одному символу |
| [`risc-iv.asm`](risc-iv.asm) | RISC-V 32 | Перестановка байтов 32-битного числа из big-endian в little-endian |

## Структура

```text
.
├── acc.asm    # Фибоначчи, acc32
├── acc.yaml   # тест acc.asm
├── f32.asm    # upper_case_cstr, f32
├── f32.yaml   # тест f32.asm
├── m68k.asm    # glob_match, m68k
├── m68k.yaml   # тест m68k.asm
├── risc-iv.asm    # big_to_little_endian, RISC-V 32
└── risc-iv.yaml   # тест risc-iv.asm
```

## Ввод и вывод

В тестах используется memory-mapped I/O:

- `0x80` — входные данные;
- `0x84` — выходные данные.

Точный формат ввода, ожидаемый результат и представление отчёта указаны в соответствующем `*.yaml`. Например, `m68k.yaml` подаёт две строки для сопоставления с шаблоном, а `risc-iv.yaml` проверяет преобразование числа `0x12345678`.
